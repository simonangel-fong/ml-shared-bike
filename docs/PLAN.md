# Plan

> Working draft — phases and scope are subject to change as the project evolves.

## Goal

- Build an ML model from the bike-share ridership dataset.
- Practice the end-to-end ML lifecycle.

---

## Phase 01 — Problem Definition

- Explore the dataset.
- Define the problem.
- Define the application scope.

## Phase 02 — Data Collection

- Data collection

## Phase 03 — Data Preparation

- Exploratory data analysis (EDA).
- Data cleaning and processing.
- Feature engineering.

## Phase 04 — ML Infrastructure

- Set up the ML infrastructure (AWS SageMaker).

## Phase 05 — Model Training

- Train models.
  - Try different models.
  - Track metrics with MLflow.
  - Evaluate the models.
- Upload the selected model to S3.

## Phase 06 — Application

- Build the application.
- Dockerize the API app.
- Build the frontend with HTML.
- Push the image to ECR.
- Test locally.

## Phase 07 — Deployment

- Deploy with Lambda + API Gateway + S3.

## Phase 08 — CI/CD

- Set up CI/CD.

## Phase 09 — Monitoring

- Set up monitoring.
